# Little Variances downloads

Official binary releases of Little Variances, an audio effect plugin that adds probability-driven gain, timing, and reverb variations to repetitive loops.

Download ZIPs from [the latest release](https://github.com/TarcanGul/little-variances-releases/releases/latest). Each release includes SHA-256 checksums.

- macOS: Apple Silicon (arm64), macOS 12 or newer; VST3, CLAP, AU, and Standalone.
- Windows: x64; VST3, CLAP, and Standalone.
- Linux: x64; VST3, CLAP, and Standalone. GCC and Clang builds are alternatives.

Extract the desired plugin into your host's plugin scan folder. Builds are unsigned; macOS builds are not notarized.

This repository hosts release downloads only. Source code and build workflows are maintained privately.
